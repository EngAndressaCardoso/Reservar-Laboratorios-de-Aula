# Reserva de Laboratorios para Aulas

## Objetivo
Criação de um protótipo web funcional para consulta e reserva de laboratórios de aula, utilizavel em computadores e celulares

## Tecnologias
- HTML
- CSS
- JavaScript
- JSON

## Funcionalidades
- Consulta de laboratorios
- Reserva de laboratorios
- Validação e confirmação de reservas
- Listagem de reservas
